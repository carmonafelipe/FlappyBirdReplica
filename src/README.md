# Flappy Bird in Java 🐦

This is a personal practice project to build a basic Flappy Bird clone using Java and Swing.

## Objective
Practice Java, object-oriented programming, game logic, and version control using Git and GitHub.

## How to Run
1. Open the project in VSCode.
2. Open `App.java` and run it using the play button at the top.

## Features to Implement
- Game window and rendering loop
- Player (bird) physics and controls
- Obstacle generation and movement
- Collision detection
- Score tracking
- Game over and restart logic
